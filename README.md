# Time & Attendance System (Java)

Java-based backend system for tracking employee time punches, applying shift rules, and calculating attendance metrics.

## Features
- Punch adjustment logic (rounding, grace periods, docking penalties, lunch rules)
- Absenteeism calculation by pay period
- DAO architecture using JDBC + MySQL
- JSON output for reporting
- JUnit test coverage

## Technologies
Java, JDBC, MySQL, JUnit, Git/GitHub

## Project Context
Team-based course project developed using an Agile (Scrum) sprint workflow.

## Setup (Local)
1. Create a local `dao.properties` file (see `dao.example.properties`)
2. Point it to your MySQL database
3. Run tests
